# ADR 0000: Short decision title

- Status: proposed
- Date: YYYY-MM-DD
- Issue: #000
- Decision owners: names or GitHub handles

## Context

What concrete problem or conflicting constraints require a durable decision?
Describe current behavior and evidence, not a hypothetical rewrite.

## Decision

State the chosen boundary or rule precisely. Include contracts, ownership, and
migration behavior where relevant.

## Consequences

What becomes simpler? What trade-offs, limitations, operational work, or
compatibility obligations does the project accept?

## Alternatives considered

List only serious alternatives and the factual reason each was not chosen.

## Verification

How will tests, live-CARLA evidence, artifacts, or review demonstrate that the
decision was implemented correctly?
