# انیمیشن‌های مفهومی کارگاه

دو انیمیشن `FrameJourney` و `PerceptionTasks` به‌طور مستقل برای این کارگاه طراحی شده‌اند؛ فیلم ضبط‌شدهٔ CARLA یا خروجی واقعی مدل نیستند. هدف، توضیح گام‌های یک فریم و تفاوت پرسش‌های تشخیص، بخش‌بندی و تخمین عمق است. خروجی‌ها بی‌صدا هستند و زیرنویس فارسی محلی دارند.

موتور رندر **Manim Community 0.20.1** است؛ این نسخهٔ اجتماع‌محور از خانوادهٔ ابزار Manim است و نباید آن را همان شاخهٔ اصلی 3b1b/manim معرفی کرد. زبان بصری از روش توضیح تدریجیِ 3Blue1Brown الهام می‌گیرد، اما انیمیشن و کد این کارگاه تألیف مستقل‌اند. [مخزن اصلی Manim](https://github.com/3b1b/manim) و [نسخهٔ Community](https://github.com/ManimCommunity/manim).

از ریشهٔ مخزن، با Manim Community 0.20.1 و فونت Avenir Next در دسترس:

```sh
manim -qh --fps 24 --disable_caching --media_dir /tmp/carla-workshop-manim docs/workshop/animations/vision_scenes.py FrameJourney PerceptionTasks
```

فایل‌های نهایی H.264 در `assets/video/` نگهداری می‌شوند. فونت مورد استفاده وابسته به سیستم رندر است؛ تفاوت فونت می‌تواند چینش و خروجی تصویری را تغییر دهد. صوت و موسیقی به کار نرفته‌اند.

## طرح آموزشی و راهنمای ساخت

- **مسیر فریم:** پرسش «از تصویر تا نتیجه چه رخ می‌دهد؟»؛ یک نشان ثابت از دوربین به آماده‌سازی، مدل و نمایش حرکت می‌کند و در پایان محدودیت تأخیر توضیح داده می‌شود.
- **پرسش‌های بینایی:** یک شبکهٔ نمادین به‌ترتیب با کادر، ناحیهٔ رنگی و طیف عمق نشان داده می‌شود؛ این تغییرات خروجی یک مدل واقعی نیستند.

برای بررسی طراحی و مسیر ساخت از [راهنمای متن‌باز Manim](https://github.com/awesome-skills/manim-skill) و دستورالعمل صحنه‌پردازی آن الهام گرفته شده است. کد و ترسیم‌های این دو صحنه برای همین ارائه نوشته شده‌اند.
