# اجرای کارگاه CARLA Vision

این نسخهٔ محلی بر مبنای موتور ارائهٔ پروژهٔ بیوانفورماتیک و فایل Markdown همین پوشه ساخته شده است. اجرا به Python 3 نیاز دارد، به اتصال اینترنت برای خود اسلایدها نیاز ندارد؛ پیوند منابع خارجی اینترنت می‌خواهند.

در مک، روی «شروع کارگاه.command» دو بار کلیک کنید. روش جایگزین: در Terminal وارد این پوشه شوید و اجرا کنید:

```sh
python3 -m http.server 8769 --bind 127.0.0.1
```

سپس در مرورگر `http://127.0.0.1:8769/` را باز کنید. با کلیدهای پیکان، PageUp و PageDown حرکت کنید؛ دکمهٔ چاپ/PDF و تمام‌صفحه در بالا قرار دارند. برای توقف، در ترمینال Ctrl+C بزنید. اگر درگاه اشغال بود، عدد دیگری انتخاب کنید.

تصاویر از مستندات همین پروژه‌اند. موتور ارائه، سبک و فونت از پروژهٔ آموزشی محلی کاربر برداشته و برای این کارگاه تطبیق داده شده‌اند. کتابخانهٔ markdown-it متعلق به سازندگان آن است و مجوز MIT آن در فایل مجاور کتابخانه حفظ شده است. زمان و مخاطب پیش‌فرض: حدود ۳۰ دقیقه برای دانشجویان و پژوهشگران؛ قابل تغییر.

مبدأ موتور نمایش و فونت: [پروژهٔ آموزشی بیوانفورماتیک](https://github.com/koolfox/koolfox.github.io/tree/main/structural-bioinformatics). فونت Arad مطابق شرایط و مالکیت موجود آن پروژه بازاستفاده شده است و این انتقال مجوز جدیدی برای فونت ایجاد نمی‌کند.
