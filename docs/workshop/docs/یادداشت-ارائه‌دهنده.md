## نکات اجرایی

- اسلایدهای تصویری عمدا کوتاه و مستقل‌اند؛ پس از دریافت ضبط‌های واقعی، تکه‌های کوتاه و مناسب برای پخش انتخاب می‌شوند. تا آن زمان از همان جایگاه‌ها برای توضیح شفاهی استفاده کنید.
- هنگام توضیح داده، فرق ضبط ویدیوی بازبینی با مجموعه‌داده پژوهشی همگام را روشن کنید؛ فریم‌های مشابه یک اجرا را میان مجموعه‌های آموزش و آزمون تقسیم نکنید.
- آموزش واقعی را از dry run جدا کنید. درباره نتایج مقاله، مقدار یا نتیجه‌ای که از اجرای معتبر به دست نیامده بیان نکنید.
- برای پرسش مقاله، ابتدا یک عامل مانند آب‌وهوا و سپس مدل، شرایط مقایسه و معیارها را مشخص کنید. مقایسه چند فریم آزمایشی برای نتیجه‌گیری آماری کافی نیست.
- در اسلاید کنترل، حالت دستی یا Traffic Manager را مطابق ضبط واقعی معرفی کنید؛ تصویر تشخیص اشیا به‌معنی کنترل خودرو توسط آشکارساز نیست.
- برای ادامه عملی، [راهنمای پژوهشگر](راهنمای-پژوهشگر.md) را در اختیار شرکت‌کنندگان بگذارید.

این زمان‌بندی برای کارگاه ۳۰ دقیقه‌ای است. ارایه مقاله در یک کنفرانس ممکن است زمان و قالب متفاوتی داشته باشد.
